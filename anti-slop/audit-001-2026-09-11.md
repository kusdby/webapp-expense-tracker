## Temuan bernomor
1. HIGH, R-27/R-26: pergantian periode gagal sebagian menyisakan transaksi periode lama di bawah judul/metrik periode baru. Reproduksi: summary berhasil, request daftar gagal; header berubah ke25 September–24 Oktober2026 tetapi rows masih Agustus/September sebelumnya. Bukti browser-4.json `before/after partial period failure`. Perbaikan yang disarankan: update tampilan secara atomik atau kosongkan panel daftar dan tampilkan error khusus scope baru, bukan rows lama tanpa penanda.
2. HIGH, R-27: summary gagal setelah autentikasi berhasil membuat app kembali ke login tanpa pesan. Bukti browser-3.json `summary failure incorrectly returns login`. Pisahkan kegagalan autentikasi dari kegagalan mengambil data; tampilkan retry dashboard.
3. HIGH, R-27/R-38: initial summary pending menampilkan Rp0 sebagai saldo/expense/income, tanpa busy/status. Ini placeholder sementara yang berpotensi disalahartikan sebagai saldo sebenarnya, bukan bukti data hilang atau fabrikasi disengaja. Bukti browser-3.json `authenticated initial pending summary`. Gunakan placeholder netral/skeleton sampai nilai diterima.
4. HIGH, R-03: dashboard overflow di viewport768px dengan nama akun panjang. Document scrollWidth1192; select accountFilter1060px. Viewport1440/390/320 tidak menunjukkan overflow dokumen dalam fixture. Bukti browser-1/2.json; screenshot /DATA/fin-reaudit-overflow-768.png. Batasi min-width/max-width pada filter dan select serta izinkan reflow tablet.
5. HIGH, R-32: fokus hilang ke BODY setelah submit gagal dan setelah edit global berhasil saat modal search masih terbuka. Bukti browser-2.json `failed save recovery`, `edit success focus and refreshed global`. Pulihkan fokus ke field/error atau kontrol hasil pencarian yang relevan setelah render. Escape normal dan fokus kembali pada pembukaan/penutupan biasa berhasil; bukan seluruh modal rusak.
6. LOW, R-15/R-16 (kejelasan copy), terkait R-27: nominal nol menghasilkan pesan generik koneksi/isian; error pencarian menyebut risiko menyimpan, meski aksi hanya membaca. Filter kosong masih `Belum ada transaksi.` tanpa membedakan hasil filter. Bukti browser-2 invalid zero; browser-3 filtered empty; browser-4 global failure. Gunakan validasi nominal >0 yang spesifik dan feedback sesuai aksi.

## Perbaikan sebelumnya yang terverifikasi pada fixture
- Scope filter lokal mengikuti salary period; search tetap global.
- Filter akun/kategori bertahan setelah pergantian periode normal.
- Pilih periode lintas tahun dan Periode ini bekerja.
- Buat akun/kategori/pengeluaran/pemasukan, edit kategori/saldo/transaksi, hapus transaksi/kategori/akun berhasil dalam fixture.
- Hasil global diperbarui setelah edit berhasil.
- Pending disable/busy terlihat; isian bertahan setelah save gagal.
- Escape dan tombol Batal menutup dialog; kembali dari nested dialog via Escape berhasil.
- Target kontrol terlihat pada matrix >=44px; mobile320/390 dan desktop1440 tidak overflow pada fixture.
